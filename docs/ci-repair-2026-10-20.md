# Academic source collection repair

## Incident

The first `Collect academic writing sources` run, [39395062196](https://github.com/PresleyRen/clearweave-skill/actions/runs/39395062196), failed with `ValueError: Missing abstract` at commit `b62f52cf8d886e4773991861769f6265065f1d77`.

The next run, [39395351921](https://github.com/PresleyRen/clearweave-skill/actions/runs/39395351921), completed after commit `ed4f3cfb49c37e992d2b0cdc99a4f637afb01976`. Inspecting its actual artifact showed five populated abstracts and an empty D16-1264 abstract carrying `error: Missing abstract`. It preserved diagnostic data but did not recover the missing input.

## Cause and repair

The selected ACL XML record for SQuAD does not include an `<abstract>` element. The paper itself does have an abstract on page 1 of [the publisher PDF](https://aclanthology.org/D16-1264.pdf). A reviewed, attributed excerpt from that page now supplies this one missing field. The original six selected papers are retained; no substitute sample was chosen.

`tools/collect_academic_sources.py` reads pinned source revisions and verifies whole-file hashes. XML abstracts take precedence. A fallback is accepted only when its paper ID, title, authors, publisher URL, page and text hash match. The result records whether text came from XML or a reviewed PDF excerpt.

The collector saves diagnostics on both outcomes and exits nonzero when any required source or abstract remains unresolved. The workflow uploads those diagnostics with `if: always()` while retaining the original failure status. Download retries are bounded and restricted to transient errors. Collection no longer depends on moving main/master branches or a GitHub API token.

The complete source replay uses the actual artifacts downloaded from GitHub run 39395351921. The smaller XML fixtures are extracted from those same source files. This is a data-pipeline and regression test, not a new model-writing experiment. No runtime Skill file was changed by this repair.

## Reproduce before pushing

With previously downloaded originals:

```bash
python3 tools/preflight.py \
  --source-cache /path/to/academic-research \
  --hc3-samples /path/to/hc3-samples.json
```

To retrieve the pinned public originals:

```bash
python3 tools/preflight.py --download
```

The command runs all tests, package validation, real ACL record checks, full source collection and HC3 diagnostic replay. `.preflight/report.json` records exit codes and SHA256 hashes of the tested working tree. It also checks that source files did not change while tests ran. Push only that tested content; rerun after any code change.

The collection workflow runs offline regressions first and then repeats the real network collection on GitHub. Historical failed runs remain as incident history; the new run and its completeness report establish recovery.
