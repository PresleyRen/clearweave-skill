# ClearWeave documentation

[简体中文](README.zh-CN.md) · [Project README](../README.md)

ClearWeave uses **English as the canonical documentation language**. Every active, user-facing Markdown document should have a Simplified Chinese mirror using the `.zh-CN.md` suffix. JSON records, source snapshots, generated test data, logs, code, licenses, and archived runtime snapshots are not translated.

## Language convention

- `name.md`: canonical English document.
- `name.zh-CN.md`: complete Simplified Chinese mirror.
- English pages link to the Chinese mirror near the top.
- Chinese pages link back to the English canonical document.
- Capability IDs, rule IDs, commands, file paths, source names, hashes, and code remain unchanged across translations.
- When the English canonical document changes, update its Chinese mirror in the same documentation change.

## Archives and machine records

Historical review notes, generated evaluation records, JSON manifests, logs, and runtime snapshots are retained as evidence and are not part of the public bilingual documentation set. The current public documentation should be reachable from this index.
