## 文件规范

- `name.md`：英文规范主文档。
- `name.zh-CN.md`：对应的完整简体中文版本。
- 英文文档顶部提供中文入口。
- 中文文档顶部提供英文返回入口。
- 能力编号、规则编号、命令、路径、来源名称、哈希值和代码保持原样，不翻译。
- 英文主文档发生实质更新时，同一次文档修改中同步更新中文镜像。

## 历史与机器记录

历史审查记录、自动生成的评测数据、JSON manifest、测试日志和历史 runtime 快照用于追溯，不属于公共双语文档集合。当前主要文档都应能从本页面直接进入。
