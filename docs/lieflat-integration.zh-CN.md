## 能力对应

| 上游能力 | ClearWeave 中的整合方式 | 路由 |
| --- | --- | --- |
| 白名单与最小改动 | 显式 `lieflat` 模式；未命中的文字和文档结构锁定 | CW49, CW53 |
| 修改前读取风格指南 | 读取指定或项目范围内的风格资料；保留作者真实标点偏好 | CW49, CW54 |
| LF01–LF09 | 每类规则都有定义、上下文例外和可定位候选 | CW50；`assets/lieflat-rules.json` |
| LF10 及五个子类型 | 五类候选分别定位，并附语义关系处理规则 | CW51 |
| LF11 段首回指 | 检查非首段中文正文第一句的回指关系 | CW50, CW54 |
| 排除常见误判规则 | 问句、被动、名词化、名词重复、句内排比和句长整齐本身不作为修改理由 | CW54 |
| 句子/段落/语料脚本 | 重新实现为 `scan`、`measure`、`compare-corpora` | CW52 |
| 最终验收清单 | 规则映射改动清单、精确重建、结构与字面检查 | CW53 |
| 后续规则扩展 | LF → CW → CF → 来源 → 实现 → 测试 | CW54 |

## 已处理的冲突

| 冲突 | ClearWeave 的处理 | 对应测试 |
| --- | --- | --- |
| 全局白名单会限制已有写作模式 | 白名单只用于明确选择的成稿精准清理 | CF35；模式路由测试 |
| 删除翻案句可能删掉真实排除关系 | 如果被排除项定义了论断边界，则保留 | CF36；否定保护用例 |
| 压缩列举可能漏掉项目 | 每个独立项目都保留，只调整连接或句法 | CF37；完整清单用例 |
| 上游把风格指南设为绝对最高优先 | 风格资料决定表达偏好；事实和当前任务仍优先 | CF38 |
| 删除“当…时”或替换“然而”可能改变逻辑 | 保留时间、条件、转折与因果关系 | CF39 |
| 研究文档与脚本的倍率方向不一致 | 新报告统一明确为 B/A；分母为零时记为 null | CF40；倍率测试 |
| 研究说按空行分段，脚本实际按行统计 | 对换行正文重新归组；代码、引用、列表、表格按支持范围排除 | CF41；解析测试 |
| 上游标题正则会误抓正文序数词 | 只处理真实标题节点；要求连续三个同层级序数标题；保留交叉引用与步骤型编号 | CF42 |
| 规则 8 涉及名词化，但研究又否定名词化作为 AI 特征 | 精准模式不设置独立名词化触发；论文语法编辑仍由原模块负责 | 非触发测试 |
| 段首回指只检查第一个字符 | 检查完整首句中的回指线索；具体指代对象仍由上下文判断 | LF11 测试 |
| “材料密度”或“恰好三个案例”容易变成泛化规则 | 不补造数据、不设置泛化阈值、不强制减少成三项以外的数量 | LF08 与叙事控制用例 |

## 工作流

```text
当前任务 + 中文成稿 + 指定范围的风格指南
    → 选择完整编辑 / 只诊断 / lieflat 精准清理
    → 锁定文档结构与信息
    → 定位 LF01–LF11（LF10a–e）
    → 逐个判断体裁、句子功能和作者习惯
    → 只做最小、可映射到规则的修改
    → 根据改动清单重建修订稿
    → 比较受保护字面内容并复核实际语义
    → 交付指定输出

语料分析：本地文本 → 相同切分规则 → 命中数 + 覆盖率 + 对应分母
          → 单文档结果 → B/A 比较 → 抽查真实命中
```

## 文件与扩展入口

规则定义：`skills/clearweave/assets/lieflat-rules.json`。编辑策略：`references/lieflat.md`。本地工具：`scripts/clearweave_tone.py`。回归测试：`tests/test_tone.py`。

主能力注册表目前覆盖 46 个来源、262 条来源决策、54 项能力和 42 类冲突。原有来源与能力全部保留。

上游项目报告了 629 篇文章的研究语料，但没有公开语料本身，因此其历史频率不被直接作为 ClearWeave 的阈值、分数或测试结论。ClearWeave 使用自己的计数定义和回归测试。某个表面候选被定位，不代表一定要改；真实对照、时间条件、比喻和作者偏好仍需结合上下文判断。
