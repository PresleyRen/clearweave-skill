# ClearWeave 0.5.0 · Academic drafting and scoped cleanup

[简体中文](v0.5.0.zh-CN.md)

Apply academic writing guidance from the first paragraph, with a distinct operation for new writing, requested polishing and minimal cleanup of finished text.

## Changed

- **Draft / Polish / Cleanup:** select the operation from the supplied material and request. Draft from the evidence map, keep polishing within the requested scope, and preserve headings, paragraph breaks, argument order and unmatched text during Cleanup. One passage has one language editor; a second generic rewrite is not required.
- **Manuscript routing:** select the section or manuscript task before the language companion. Reuse the existing evidence map and the relevant section, journal or formal-writing guide. English academic output follows the academic route even when requested in Chinese; the bundled route remains usable offline.
- **Source-specific guidance:** retain the pinned junbolian Academic Humanizer and add its independently verified examples file. Add AIScientists-Dev guidance under `academic-humanizer-evidence`. The reader distinguishes the two same-named upstream projects by their full file digests and fixed source locations, with explicit offline failure instead of silently switching sources.
- **Scientific preservation:** adapt upstream guidance without importing invented facts, statistical-summary changes, deleted reproducibility settings, blanket word bans or punctuation quotas. Keep the publication-readiness handoff separate from language editing.
- **LaTeX literals:** detect changes to supported labels and cross-reference keys, including keys without numbers. Common direct commands have their own `latex_reference` category; arbitrary macros and unchanged identifier inventories still need semantic review.
- Record both academic sources, their licenses, adoption decisions and bilingual conflict cases. Preserve the historical scholarly and lieflat evaluation snapshots.

## Validation record

The recorded local validation passed **411 deterministic tests** on Python 3.12.14, together with package/source checks, generated-document checks and the official skill structure validator. Three actual pinned rule files were read exactly in offline mode; swapping the two local sources was rejected.

A fresh-context paired trial covered four synthetic requests: drafting English Results from Chinese notes, minimal LaTeX cleanup, preserving already clear prose and correcting only subject–verb agreement. A separate reviewer, without the condition mapping, rated **all four comparisons as ties** and found no fidelity or scope violation in either condition. The three existing-text cases in both conditions also matched their scoped expected text exactly. The unchanged prose case remained unchanged.

These are targeted regressions with model-based review, not evidence of general writing-quality improvement. They do not establish long-document performance, automatic skill triggering, live external-guidance effectiveness, detector scores or publication acceptance. The raw requests, outputs, review and limitations are linked in the [evaluation record](../evaluation-academic-humanizer.md). Published-commit CI is reported in [GitHub Actions](https://github.com/PresleyRen/clearweave-skill/actions/workflows/validate.yml).

## Release handling

Routine CI runs offline tests and package checks on main pushes and pull requests, cancelling superseded runs. Source collection, historical network checks and publication run only when manually requested. Explicit publication uses `validate_repo.py --release` to require notes matching `VERSION`; ordinary editing does not require release notes. An existing release or tag is preserved without replacing its content.
