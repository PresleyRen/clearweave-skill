# ClearWeave v0.2.0 · Traceable bilingual editing / 可追溯双语编辑

One English–Chinese skill, a shared preservation-first contract, and scoped language/genre modules. Clear names the goal; Weave describes combining complementary methods without stacking contradictory filters.

## Added

- A registry of **36 bounded capability families**, with rule locations, source links, conflict scenarios, and implementation boundaries.
- A crosswalk for **all32 inventoried sources and194 documented audit decisions**:92 adopted and102 adapted/excluded. This is not an exhaustive inventory of every upstream subfile or feature.
- **26 conflict families**, each with English and Chinese authored fixtures:52 faithful/counterexample pairs checked against explicit constraints.
- `clearweave_risk.py`: read-only R01–R08 cue and numeric-order candidates; no semantic-equivalence verdict.
- `clearweave_trace.py`: locate a symptom, capability, conflict, or source in the runtime modules and regression map.
- File/batch safety, long-document continuity, voice-profile maintenance, privacy boundaries, and extension guidance.
- Full English/Chinese capability tables, text architecture diagrams, and a generated atlas. `tools/render_catalog.py` detects stale tables.
- Explicit Traditional Chinese variants for existing linter phrase families; no script conversion or complete regional lexicon.

## Verification and limits

- **179 deterministic local tests passed** on Python3.13.5;52 fixture and32 source-link tests are included in that count.
- Source crosswalk and generated documentation validation passed.
- Actual temporary-project installation and installed-helper execution passed.
- **12 same-session author-applied examples** include raw inputs, outputs, self-review and actual helper reports. These are not independent, blinded or comparative trials.
- The previous18 paired model outputs and4 regressions remain historical v0.1 evidence, not newly rerun v0.2 evidence. That comparison had one preference for each condition and16 ties.
- Fixed the `May 12` date/modal collision. Tests retain known semantic blind spots and legitimate false positives.

A green test suite is not a guarantee of naturalness or unchanged meaning. No commercial detector was tested; no “human percentage,” zero-drift promise, fabricated experiences, or hidden unfavorable results are bundled. The host performs writing; Python only checks and indexes limited features.

## Install

```bash
git clone --branch v0.2.0 https://github.com/PresleyRen/clearweave-skill.git
cd clearweave-skill
python3 tools/install_skill.py --project /absolute/path/to/your-project
```

The installer refuses to overwrite an existing skill directory. Review and back up customizations before replacing an older installation. GitHub publication does not automatically install the skill or list it in a marketplace.
