# ClearWeave 0.3.0 · Scholarly

English–Chinese natural prose, direct research writing, academic grammar and sample-grounded voice in one installable skill.

## Added

- Dedicated anti-defensive editing, contribution framing, grammar and author-voice modules.
- 13 new scholarly/style sources; 45-source registry with 246 mapped decisions.
- 48 capability families, a complete function diagram, 34 conflict families and 68 bilingual fixtures.
- Read-only scholarly scanning, corpus profiles, profile comparisons and scoped draft/final preference proposals.
- Copy-ready academic prompts, traceable maintenance routes and English/Chinese READMEs.

## Tested

287 local deterministic tests passed, including new helper and provenance regressions. Actual installation and all four new helper commands ran successfully. Public-data applications use three separate field-profile abstracts, six editing abstracts and two Chinese HC3 answers: six revisions and two unchanged controls. The SQuAD abstract was recovered from its reviewed PDF page 1. Raw inputs, outputs, hashes, the self-review repair and helper reports are included. Revisions and semantic review were performed by the same assistant; these are application examples rather than an independent model benchmark.

## Start

```bash
git clone --branch v0.3.0 https://github.com/PresleyRen/clearweave-skill.git
cd clearweave-skill
python3 tools/install_skill.py --project /absolute/path/to/your-project
```
