# ClearWeave 0.5.0 · 学术起草与限定范围清理

[English](v0.5.0.md)

从第一段开始应用学术写作规则，分别处理新文本起草、按要求润色和成稿的最小清理。

## 更新内容

- **Draft / Polish / Cleanup：**根据材料和请求选择操作。Draft 依据证据表起草，Polish 限于用户要求，Cleanup 保留标题、分段、论证顺序和未命中的原文。同一段落只由一个语言编辑器处理，不要求再做一次通用改写。
- **文稿路由：**先选择章节或文稿任务，再选择语言指南。复用现有证据表及适用的章节、期刊或正式写作指南。即使用中文提出请求，英文论文输出仍走英文学术路径；内置流程可以离线使用。
- **按来源读取指南：**保留固定版本的 junbolian Academic Humanizer，新增独立校验的 examples 文件。以 `academic-humanizer-evidence` 别名接入 AIScientists-Dev 指南。读取器根据完整文件摘要和固定来源地址区分两个同名上游，离线无法匹配时明确失败，不静默切换来源。
- **科学内容保留：**调整上游规则时，不引入虚构事实、统计汇总方式变化、可复现设置删除、统一词汇禁令或标点配额。投稿就绪审查继续与语言编辑分开处理。
- **LaTeX 字面保护：**识别受支持标签和交叉引用键的变化，包括不带数字的键。常见直接命令使用独立的 `latex_reference` 类别；任意宏及标识符总量未变的情况仍需语义复核。
- 记录两个学术来源、许可证、采纳决定和双语冲突场景，保留既有 scholarly 与 lieflat 评估的历史快照。

## 验证记录

已记录的本地验证在 Python 3.12.14 下通过 **411 项确定性测试**，包结构与来源检查、生成文档检查及官方 Skill 结构验证也均通过。三个实际固定来源文件成功离线精确读取；故意交换两个本地来源时，读取器均拒绝采用。

新上下文配对试跑覆盖四个合成请求：根据中文记录起草英文 Results、最小 LaTeX 清理、保留已清楚的正文，以及仅纠正主谓一致。独立上下文的评审未获知条件映射，判定**四组比较全部为平局**，没有发现任一条件的保真或范围违例。两种条件下的三个已有文本场景也均与限定范围内的预期文本完全一致；无需修改的正文保持原样。

这些是由模型评审的定向回归，不能证明写作质量普遍提升，也没有验证长文表现、技能自动触发、实时外部指南的写作效果、检测器分数或投稿录用结果。原始请求、输出、评审及限制见[验证记录](../evaluation-academic-humanizer.zh-CN.md)。已发布提交的 CI 结果另见 [GitHub Actions](https://github.com/PresleyRen/clearweave-skill/actions/workflows/validate.yml)。

## 发布处理

日常 CI 仅在 main 推送和 PR 上执行离线测试与包结构检查，并取消已被新提交取代的运行。资料采集、历史联网检查和发布均改为手动。明确发布时使用 `validate_repo.py --release` 要求存在与 `VERSION` 对应的说明，普通编辑不受发布说明约束。已有 release 或 tag 保持原样，不覆盖其内容。
