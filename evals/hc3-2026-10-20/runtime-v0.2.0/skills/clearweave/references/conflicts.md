# Resolve conflicting advice

Apply the current user's requested scope and output first. Within that scope, preserve facts and the claim's conditions, respect the genre and voice, then improve expression. A style preference never supplies missing evidence.

| Conflicting source advice | ClearWeave decision | Reason |
| --- | --- | --- |
| Remove every caveat versus defend every claim | Keep caveats that change interpretation; trim repeated or empty apologetic framing | Precision and directness can coexist |
| Always use active voice versus prefer impersonal science | Name an actor when established and useful; retain passive voice when the action or object is the focus | Voice serves meaning and genre |
| Ban em dashes, adverbs, triads, connectors, or specific words | Inspect function and local overuse; apply a ban only if the user explicitly requests it and meaning can be preserved | Surface features do not establish a defect |
| Add emotion, anecdotes, opinions, or imperfection | Keep supplied voice and experiences; invent only for explicitly fictional tasks | A more personal tone must not fabricate a person |
| Increase sentence-length variation or lexical entropy | Vary construction only to improve relationships and pacing | Numerical distribution is not a writing objective |
| Replace repeated technical vocabulary with synonyms | Keep stable technical terms; reduce redundant surrounding explanation | Synonyms can change the concept |
| Make the strongest possible narrative | State the actual contribution alongside material limitations and adverse evidence | Selective reporting misleads readers |
| Reframe a losing comparison around a winning metric | Explain which metrics were evaluated and what each supports | Changing the success criterion after observing results conceals evidence |
| Voice samples override all rules | Current instructions outrank samples; samples guide expression without importing facts | The task and audience may have changed |
| Aggressive editing proves value | Prefer the smallest useful change and allow a no-op | Good prose should survive the editor |
| Repeated loops until a score passes | One edit plus one targeted repair, then stop or expose a real blocker | Repeated optimization can flatten voice and accumulate drift |
| Style score equals probability of AI authorship | Report located style findings only | No calibrated authorship inference is implemented |
| Send the text to a hosted detector by default | Do not send text anywhere as part of this skill | Local editing requires no external detector |
| Use a single Chinese regional vocabulary everywhere | Keep the input variety; localize only as requested | Script, region, and register are separate choices |
| Reject all English work in a Chinese skill, or all translation in an academic skill | Route language and genre separately; translate only on request | A common preservation contract supports both languages |
| Update a persistent blacklist whenever a phrase is disliked | Treat task-specific preferences as local; change persistent assets only when requested | A single example is not a universal rule |
| Always produce a long critique or a fixed rejection ratio | Match the requested task; distinguish observed problems from questions | Critique should reflect the evidence |
| Always ask for an audience, model, detector, and samples | Infer routine choices and proceed; ask only about a material ambiguity | Most edits have enough context already |

If the user requests a hard surface constraint that conflicts with exact quotation or another protected span, retain the protected span and briefly identify the conflict outside the text. Do not silently change source evidence to satisfy a cosmetic rule.
