# Initial instruction snapshot

The files in `initial-instructions/` reproduce the Markdown and UI metadata recorded by `generation-manifest.json` for the original 18-case comparison. Each file was checked against its recorded SHA-256. The snapshot excludes the independently developed optional checker/tooling documentation that was not present at that review-preparation point. It is evidence for the prose-instruction test, not a standalone release package.

After the comparison, two passages were added to the current main skill and preservation reference to distinguish generic product aspirations from substantive preferences and conditional plans. The four post-refinement requests and their actual outputs are retained separately. The current installable package is `skills/clearweave/`.
