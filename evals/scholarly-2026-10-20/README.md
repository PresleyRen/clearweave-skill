# Public scholarly application record

`samples.json` contains three field-profile abstracts, five usable editing abstracts, one missing-abstract record, and two historical Chinese HC3 answers. `outputs.json` records six edits, one unchanged control and one missing-source exclusion. `field-profile.json` contains descriptive measurements and assistant-interpreted traits; `profile-measurements.json` is the direct helper output.

`protocol.json` records selection, requested operations, generation method and runtime hashes. `report.json` contains actual helper outputs. `installed-smoke.json` records installed-helper execution. `unittest.log` and `environment.json` record the local regression run.

ACL excerpts and their adaptations are CC BY 4.0, attributed per sample. HC3 excerpts and their adaptations are CC BY-SA 4.0, with original dataset repository, commit, line and field. Original ClearWeave scripts are MIT. These sample licenses remain separate from the project code license.
