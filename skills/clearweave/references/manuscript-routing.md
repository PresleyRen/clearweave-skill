# Select a manuscript workflow before drafting

Keep ClearWeave as the entry point. Select one primary task by the deliverable, then apply only the language guidance needed for the requested passages. A request in Chinese for English Results selects English prose. For a request spanning stages, use each relevant guide once at its stage. When Paper Draft, ReviewCraft or another owning skill already supplies the evidence map and section plan, reuse them and go directly to the language route; do not send the task through another manuscript planner. Keep research logs and editorial notes out of clean copy.

| Situation | Primary skill or built-in method | How to use it |
| --- | --- | --- |
| Experiment files or scattered notes; “what can we claim?” | ClearWeave evidence mapping below; use paperwriter's evidence reference for a multi-file project | Extract results first. If the task is only an evidence audit, deliver the mapping and gaps without generating manuscript prose. |
| Draft or substantially reorganize a section or full paper, including Results or Discussion | Existing section plan, or nature-writing with its workflow reference when planning is needed | Identify article type, section and requested journal. Plan the evidence order once. Before the first English paragraph, apply **Draft** in [academic-humanizer.md](academic-humanizer.md). Use generic conventions unless a venue was specified. A short local edit needs no full-paper plan. |
| Learn target-journal expression, adapt a manuscript for transfer, or align submission files | paperwriter; load evidence guidance for exemplars, consistency guidance for a submission package | Separate the sample papers from the author's evidence. Learn paragraph tasks and terms from relevant, inspected papers. Cite a target-journal article only when it supports the particular claim. Cross-check manuscript, tables, supplement and letter when supplied. |
| Polish a technical passage or LaTeX with definitions, assumptions, theorem text, equations, labels or citations | **Polish** or **Cleanup** in [academic-humanizer.md](academic-humanizer.md) for English; the corresponding language guide otherwise | Identify protected source spans first. Preserve their scientific content and identifiers when editing surrounding prose. Use the original manuscript or proof for any requested substantive change. Minimal cleanup keeps structure and unmatched spans exact. A grammar-only edit stays within grammar. |

| Message, README or email; diagnostics only; Chinese finished-draft precision cleanup | Existing ClearWeave language, diagnosis or lieflat route | Preserve the requested output and editing scope. Use OpenAI's audience–purpose–materials approach and the author's approved sample when helpful. The blog and writing guide are method sources; neither requires a runtime call. English academic minimal cleanup follows the academic route above. |

For a selected external specialist, read its pinned instructions with the companion reader in the installed skill directory. For example, run `python3 scripts/read_companion.py nature-writing`, then `python3 scripts/read_companion.py nature-writing --resource workflow`. For `paperwriter` use `--resource evidence` or `--resource consistency`. The academic guide specifies the `academic-humanizer` source, its `--resource examples` and the optional evidence/style extension; its scoped adaptations govern their use. A matching local skill directory or an accessible pinned source suffices. Honor offline requests with `--offline`. Fetch only instructions, never send manuscript content. The reader does not execute upstream scripts. Read each chosen guide once per task. If a file is unavailable, apply the bundled workflow and distinguish that fallback from a successful external call when reporting what ran.

## Use an evidence map while writing

1. For each central claim extract **actor/method and comparator → metric/value/unit/denominator → dataset, population and condition → status/uncertainty → source locator**. For prior work bind **specific claim → paper and page/table/passage actually inspected**. For a theorem bind **conclusion → exact assumptions and proof location**. One sentence needs only a quick check; a section with multiple results benefits from a working table. Record conflicting evidence and unmeasured outcomes. Missing evidence limits what can go into the draft.
2. Give each paragraph one job. In Results, start with the comparison answering the research question, report the relevant evidence, and keep material adverse results visible. Use captions or supplementary material for secondary detail. In Discussion, separate observations from explanations and connect each limitation to the conclusion it restricts. For abstracts preserve any condition needed to interpret the main result even when read alone.
3. For a target journal, learn terminology, evidence placement and paragraph order from comparable articles of the same type. Keep current journal instructions separate from observed conventions. Preserve the author's claims and wording of quotations; copy no distinctive phrasing from exemplars. If sources are unavailable, use subject-appropriate generic prose and avoid claiming venue-specific verification.
4. Before delivery, read each important sentence back against its evidence row. Verify which method owns each value, the direction of comparison, theorem preconditions, and which reference supports which proposition. Repeat for abstract, main text, captions and supplement when in scope. A related citation, a matching numeral or a clean script report alone cannot verify these relationships. For original/revision pairs, `scripts/clearweave_risk.py` can flag some exchanged numeric/citation contexts and changed assumption words. For a first draft, use the underlying records directly.

For example, an experiment row “baseline / errors = 11 of 120” and a second row “adapted / errors = 8 of 120” allow the corresponding offline comparison. They contain no measurement of latency or statistical significance. If a cited paper reports retrieval, keep its reference on the retrieval claim; a citation present beside an unrelated latency claim still needs repair.
