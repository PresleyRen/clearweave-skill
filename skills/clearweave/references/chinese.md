# 中文编辑规则

<a id="cw02"></a>
<a id="cw12"></a>

本模块处理中文及中英混排正文。先按主技能确定编辑范围，再使用下面的文体和语言规则。英文论文正文继续保持英文；中文讨论、译文或解释分别按其交付要求编辑。

## 文体路由

使用用户明确指定的文体；没有指定时，根据原稿、目标读者和交付位置判断。混合文体按段落功能处理，例如技术博客中的实验段保留学术表达。线索不足时，保持原文正式程度和人称，先完成不依赖额外背景的修改。

| 文体 | 编辑重点 | 必须保留的功能 |
| --- | --- | --- |
| 学术／技术 | 说清研究对象、操作、证据和适用条件；减少没有内容的评价；拆解妨碍理解的长句 | 定义、术语、论证顺序、方法步骤、引用、数值精度、限定语、必要被动和对照实验中的重复 |
| 商务／公文 | 写清责任人、行动、期限、条件和请求；减少重复礼貌语或抽象口号 | 正式程度、称谓、落款、承诺强度、例外条款、批准状态、价格及时间范围；不得替组织新增保证 |
| 新闻／资讯 | 让事实、来源和引语对应；精简含混宣传语；整理事件顺序 | 谁陈述了什么、何时发生、核实状态、直接引语、相反证据；不得把报道对象的观点改成编辑自己的断言 |
| 博客／社媒／个人评论 | 推进文章主线；保留作者已有的判断、幽默和叙述节奏；去掉可套用到任意主题的开场和收尾 | 真实经历、已有态度、面向读者的语气和必要细节；不得为了显得亲切新增体验、情绪、抱怨或购买记录 |

文体决定表达方式，不能取消信息保全要求。正式评论可以有立场；编辑已有评论时，只能保留和澄清作者的立场。用户另行要求拟写观点时，将新建议与原稿内容区分。

## 主张与语义保全

把每个有独立含义的主张拆成下列项目，在修改前后对应核对：

- **主体与行为**：谁做了什么，对什么对象起作用；不要用未给出的施事者补齐主动句。
- **否定与量词**：没有、尚未、仅、至少、至多、部分、全部、分别。保留否定作用范围，不把“并非所有”改成“所有都不”。
- **条件与例外**：如果、只有、除非、在……条件下、除……之外。不因缩句改变必要条件和充分条件。
- **时间与状态**：计划、正在、已完成、暂停、截至何时，以及事件之间的先后关系。
- **比较与指标**：比较对象、分母、单位、基线、区间、误差和评估范围。不要把相对变化改成百分点变化。
- **证据与强度**：观察、相关、推测、支持、证实；保留出处和陈述主体，不把缺少反证写成效果已获证明。

语义相同的自然改写可以改变句子结构；用户锁定的字符串、直接引语、代码、公式、数据表和引用标识按保护要求原样保留。

没有数据的具体效果不能靠写作补出来。原稿存在无法确认的事实时，在纯润色中保留原有归因和确定程度，把核查建议放在正文之外；若用户授权事实核查或实质修改，再根据证据修正。不要仅删除“有人认为”就把其后的主张变成无条件事实。

## 按表达功能诊断

先指出一句话影响理解的原因，再决定是否修改。单个词、四字格、整齐句式或标点都不是删除依据，也不能用于判断作者身份。

| 观察到的形式 | 要问的问题 | 合适的处理 |
| --- | --- | --- |
| 抽象动词与大词连续出现 | 句子是否说明主体、动作、对象或结果？ | 用原稿已有的信息说清动作；没有细节时保持概括，不补造指标或案例 |
| 三项并列或重复结构 | 三项是不同要求，还是同一判断换词重复？ | 保留独立要求；合并实质重复。不为了避免“三段式”删掉一项 |
| 长篇预告、标题复述 | 是否提供新的条件、定义、问题或阅读路线？ | 删除无新增信息的复读；保留长文中有用的导航 |
| 每段都有价值升华 | 收尾是否增加推论、边界、行动或有依据的结论？ | 删除纯粹赞美；保留论证所需的局部结论 |
| “不是……而是……” | 前后差别是否排除了一个真实误解或区分两种机制？ | 差别有内容就保留；只有空泛拔高时直接说中心意思 |
| “值得注意”“需要强调” | 后面是否确实存在容易遗漏的重要限制？ | 可以直接把限制放在句首；不能连同限制一起删掉 |
| 过于整齐或过于零碎的节奏 | 是否增加阅读负担、打断关系或抹平作者习惯？ | 根据含义拆合句子；不规定句长比例，不随机制造长短差异 |

## 中文句法与连接关系

处理翻译腔时检查依存关系，不按“的”“被”“进行”的数量打分。将拥挤的修饰语移成分句时，明确它修饰哪个对象；压缩名词化表达时，保留时态、次数和范围。省略重复主语只在指代仍然清楚时进行。

区分“可以删掉的套话”与“承担逻辑关系的连接词”：

- **顺序**：“先”“随后”“最后”可以承载操作依赖。不得为了去模板打乱先验证、再执行的流程。
- **并行**：“同时”“与此同时”表示时间重叠；替换成“随后”会改变事实。
- **因果**：“因此”“导致”承诺因果关系。只能在原稿已有该关系且保持证据强度时使用，不能给相关性补因果。
- **转折与让步**：“但”“尽管”可以保留反证或限制，不能只留下正向半句。
- **范围与条件**：“仅在”“对于”“就……而言”可能限定结论对象，不应作为翻译腔一律删除。

允许简洁而完整的中文书面语。把“进行了检查”改为“检查了”可能更直接，但“计划进行检查”仍须保留计划状态。不要把结构编辑变成逐词同义替换。

## 学术和技术文本的保留项

保留能够帮助精确理解的重复。同一个指标、变量、模型或数据库对象持续使用同一名称；不要轮换近义词来制造变化。对照实验保持可比较的句式，列表中的约束不合并成含混概括。

保留必要的被动句：受试对象或处理结果可能是段落主题，施事者也可能未知。只有原稿明确谁实施操作、且主动句更清楚时才转换。

保留定义和科学限定。把连串含混语气压缩成清楚的证据边界，但保留“可能”“在本数据集上”“未达到显著性”等决定结论范围的内容。“未发现差异”不能改成“两者等效”；小规模观察不能改成普遍优势。

保留必要的段落结构、编号、表格和总结。方法部分的步骤、结果部分的基线比较、讨论部分的局限有明确功能，不因外观规整而删除。机制解释所需的长句可以保留；能够独立陈述的多个关系可以拆开。

## 作者声音与个人经历

从用户提供的样稿中提取称谓、人称、句式、常用词、节奏和正式程度，再应用到目标稿。样稿中的经历、数据、态度和结论不能迁入目标稿。样稿允许帮助表达，不能充当事实来源。

没有样稿时，沿用目标稿已经呈现的声音。不要统一加上“说实话”“我当时很震惊”等情绪标签；不要为客观报告补成随笔，也不要替社媒作者编造到店、试用、加班或对话经历。

用户明确要求虚构作品时，可以在虚构范围内创作细节；仍须遵守任务指定的叙述设定。不能将虚构细节混入事实性文章或学术记录。

## 中英混排与地区用语

以明确受众和项目规范选择语言、简繁体与地区词汇。未指定转换时保持输入习惯；“去 AI 味”本身不授权翻译、简繁转换或地区改写。繁体中文不自动等于台湾中文，也不能把香港、澳门或其他地区的正常用语标成错误。

面向台湾读者且用户要求本地化时，按语境采用当地惯用表达；保护引用、机构正式名称、品牌名、产品界面标签和代码标识。遇到会改变技术含义的词汇，不做机械地区替换。

英文缩写、模型名、API 字段、函数名、文件名和 URL 按原文或项目约定书写。首次出现时，只为理解需要补充经过确认的中文释义；不能把每个英文词都翻译，也不能把近似释义当成专有名称。

中文标点、中英空格和数字格式在可编辑正文中保持一致，服从目标出版规范或用户样稿。直角引号、破折号和全角括号可以是正常选择；不要全局清零。代码、直接引语、数学式和受保护字符串不跟随正文做格式替换。

## 原创示例

以下均为本技能编写的假设教学句，不是实验结果、真实经历或对来源项目例句的改写。“应避免”展示会改变语义或强造文风的处理。

| 原稿 | 应避免 | 可采用 |
| --- | --- | --- |
| 我们计划在 11 月对 160 份匿名报告进行复核，目前尚未开始；这项复核不包括附录。 | 我们在 11 月复核了全部报告及附录。 | 我们计划 11 月复核 160 份匿名报告，不含附录。目前尚未开始。 |
| 只有服务端确认撤销成功后，客户端才会停止轮询。 | 客户端会停止轮询。 | 客户端仅在服务端确认撤销成功后停止轮询。 |
| 缓存命中率提高与延迟下降同时出现，但尚不能判断二者是否存在因果关系。 | 缓存命中率提高降低了延迟。 | 缓存命中率上升时，延迟也下降了，但两者的因果关系尚不明确。 |
| 检索器 A 的 Recall@10 为 0.71，检索器 B 的 Recall@10 为 0.73。 | A 表现出较强检索潜力，B 则带来了出色的覆盖能力。 | 检索器 A 的 Recall@10 为 0.71，检索器 B 为 0.73。 |
| 这是一份由我们昨天导出的包含 36 条失败记录的日志。 | 昨天发生了 36 次故障。 | 这份日志是我们昨天导出的，包含 36 条失败记录。 |
| 这家书店周三营业到晚上九点。 | 我周三在店里坐到九点，舍不得离开。 | 这家书店周三营业到晚上九点。 |
| 维护人员表示，新配置可能减少重试；团队尚未验证这一判断。 | 新配置减少了重试。 | 维护人员认为，新配置可能减少重试，但团队尚未验证。 |

## 交付检查

完成一遍内容核对和一遍阅读核对：

1. 原稿的每项独立信息仍可定位；新增细节都能在授权材料中找到，纯表达调整没有偷换主张。
2. 否定、条件、时间、状态、比较对象、量词、数值和归因没有改变；不确定性与证据强度对应。
3. 文体、人称、地区用语和正式程度符合目标；样稿的风格没有携带样稿的事实进入正文。
4. 连接词、重复、术语、被动、列表和总结按功能保留或调整；没有为了满足次数或比例指标强改。
5. 核查建议、修订说明和自我评价留在用户要求的位置；最终正文不机械追加“原文未说明”等审校口吻。

发现具体问题后修正相关段落，再检查受影响的关系。没有实质问题时允许原样交付；不要为了证明处理过文本制造改动，也不要以检测分数或主观“人味分”替代语义核对。
